# 邮件整理

邮箱里的事，散在几百封邮件里：同一件事隔了三周又来一封，靠翻历史才能想起上次说到哪。
这个插件把它变成一份**能回看的报告**：抓邮件 → 打标签、写一句话 → 把有来往的邮件并成一条线程、
梳理时间轴并总结 → 生成报告 → 用 DSH 里的通知提醒你。

自动跑：按你设的周期由 DSH 的计划任务触发，只投递到一个固定的会话里，不会每次开新对话。

## 它做什么

- **抓**：IMAP 收件箱（QQ / 163 / Gmail / 自建都行，用**授权码**），按 Message-ID 去重，正文存本地，
  不删信、不改已读。
- **分**：每封邮件打 1–3 个标签（不强行归一个分类，标签可以是新词）、写一句话摘要、
  标优先级和「要不要我回复」。
- **串**：靠 `In-Reply-To` / `References` 把邮件并成线程；没有邮件头的，用「同主题 + 有共同联系人」兜底。
  线程的「到现在的总结」由模型写；新邮件进来后重算线程，**旧总结会接上**（报告里会标出这条总结覆盖到第几封）。
- **报**：只提炼成「重点 / 需要你处理 / 线程进展」三段，再附标签分布和一份只列标题的折叠清单——
  整理的价值是让你不用逐封看，而不是把邮件抄一遍。每份报告落盘三份（json / html / md）并登记，
  设置页里能回看、能删，点开在右侧边栏面板里看，面板里还能「在浏览器打开」。
- **通知**：DSH 页面开着时，客户端每 10 秒查一次最新报告；发现有新报告就在右下角弹一张卡片，
  同时（浏览器允许的话）发一条系统通知。卡片不会自己消失：点「看报告」直接打开全文，
  点「稍后」或 × 只是记住这份不再弹，**不改报告的未读状态**。
  没有新整理结果的那一轮不生成报告，也不会弹卡。

## 多个邮箱

可以配多个邮箱，每个邮箱有自己的授权码（各自存在 DSH 凭据库里）。数据是一起存的，
但**按邮箱分开看**：「邮件」「报告」页签上方会多出一排邮箱 chip，点哪个就看哪个；
线程也按邮箱隔离——同一件事在两个邮箱里各收到一份，不会被并成一条。

自动整理是**一轮把所有邮箱都跑一遍**，每个邮箱各出一份报告、各弹一次通知。

## 用法

1. 「设置 → 邮件整理」→「配置」页签：先在「邮箱服务商」下拉里选一家（QQ / 163 / 126 / Gmail /
   Outlook / iCloud / Yahoo / 阿里 / 新浪 / 搜狐 / 腾讯企业邮…），服务器和端口会自动填好；
   选「其他」才需要自己填主机和端口。然后填账号和授权码，点「测试连接」。
   收件箱固定用 INBOX，不用填。同一个页签下半部分是标签清单（只是给模型的起点，
   整理时出现的新标签会直接用上，不需要的删掉即可）。
2. 手动整理：在对话里说「整理一下邮件」。模型会 `mail_fetch` → 逐封 `mail_file`
   → 对涉及的线程 `mail_thread` 读历史、`mail_thread_summary` 写总结 → `mail_report` 出报告。
3. 自动整理：「自动」标签页里打开开关，选「每隔 N 小时」或「每天 HH:mm」，保存。
   它会在 DSH 里建一条名为「邮件整理」的计划任务，到点跑一次，跑完生成报告并通知你。
4. 回看：打开插件就是「报告」页，按时间列出所有报告，未读的有标记；点一条在右侧边栏打开摘要面板，
   面板右上角「在浏览器打开」会打开本地生成的网页版（`reports/<id>.html`）。
   想马上跑一轮，点右上角「立即整理」——它借计划任务在几秒后投递一次，生成完弹通知。

## 数据与隐私

- 账号（不含密码）在 `$DSH_HOME/mail-digest/account.json`（账号列表）；授权码在 DSH 凭据库，
  每个邮箱一个键：`DSH_MAIL_DIGEST_MAIL_<账号ID>`，旧版的 `DSH_MAIL_DIGEST_MAIL` 仍作为回退；
  也可以用同名环境变量。
- 目录里还有 `messages.json`（邮件与标签摘要）、`threads.json`（时间轴与总结）、
  `reports.json` + `reports/`（每份报告的 json / html / md）。界面不显示这些路径，需要备份或清理时按这个结构找。
- 邮件正文存在 `$DSH_HOME/mail-digest/messages.json`（每封最多 2 万字符，权限 0600），
  线程在 `threads.json`，报告在 `reports/<id>.md`，索引在 `reports.json`。
- 联网只有「测试连接」和「抓取」，都是只读；整理、总结、出报告都在本地完成。

## 限制

- 只读邮箱：不回信、不删信、不改已读状态。
- 不保存附件内容，只记文件名；抓取时仍会完整读取整封信。
- 一次最多抓 500 封，时间窗口最大 3650 天，正文超过 2 万字符会截断。
- 自动整理依赖 DSH 的计划任务服务：Host 没运行时任务不会跑（漏掉的只补最近一次）；
  第一次触发会建一个会话，之后都投递到同一个会话。
- 线程靠邮件头和主题判断，跨主题的同一件事不会被自动串起来。
